# MainWindow Tecplot 风格 UI 布局方案

本文档记录 FEModelViewer 后续 MainWindow UI 重构的目标布局。整体参考 Tecplot
这类工业 CAE 后处理软件：强调密集但清晰的信息组织、稳定的模型树/属性区、中央
3D 视口和底部工作流面板。

## 总体布局

```text
┌──────────────────────────────────────────────────────────────────────────────┐

├──────────────────────────────────────────────────────────────────────────────┤
│ 主工具栏                                                                    │
│ [打开] [保存] [导入结果] | [选择] [平移] [旋转] [缩放] [适配] | [截图] [导出] │

│ 视图/后处理工具栏                                                           │

├───────────────┬──────────────────────────────────────────────┬───────────────┤
```

## 布局原则

1. RHI 不放在主操作流里

RHI 切换当前已改为写入配置、重启生效，因此它更适合放在第二行工具栏右侧或设置菜单中。
界面只显示当前 RHI 和下次启动首选 RHI，不在运行时销毁/重建视口。

2. 左侧只管模型结构

左侧区域用于模型树和结构导航：

- 模型树
- 部件列表
- 结果字段列表
- 部件显隐、锁定、颜色、查找

3. 右侧只管当前对象和显示参数

右侧区域用于当前选择和显示控制：

- 当前选择详情
- 节点 / 单元 / 部件属性
- 坐标和结果值
- 显示样式、透明度、颜色、拾取信息

4. 底部放工作流面板

底部标签页承载按任务组织的工作流：

- 文件导入
- 结果场
- 变形动画
- 过滤 / 切片
- 查询 / 探针
- 日志 / 监控

5. 工具栏分两层

第一层工具栏放通用操作：

- 打开
- 保存
- 导入结果
- 选择 / 平移 / 旋转 / 缩放 / 适配
- 截图 / 导出

第二层工具栏放分析和后处理操作：

- 节点 / 单元 / 部件拾取
- 云图
- 变形
- 切片
- 等值面
- 阈值
- RHI 状态

## 第一轮低风险改造范围

第一轮只搭 UI 骨架，不改变核心业务逻辑：

- 增加菜单栏
- 将顶部工具栏拆成主工具栏和视图/后处理工具栏
- 调整左侧、右侧、底部区域命名
- 增加空按钮作为后续功能入口，但暂不接业务逻辑
- RHI 入口只保存配置并提示重启生效

## 暂不在第一轮处理

- 不重写渲染后端
- 不重写导入/结果解析业务
- 不引入新的 UI 框架
- 不做大规模视觉换肤
- 不把 RHI 切换恢复为运行时热切换
